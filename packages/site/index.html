wirelab

A catalog of browser protocol clients, and a campaign that tests each one and fixes its bugs.

    The order of the campaign

    The campaign tests the packages in this order. The score of a package is its reach times the chance that a fix lands. Select a package to show the parts of its score and its faults.

    Score Reach that the chance takes away

      The faults that the campaign found

      Each fault is a test that fails on a published version of a package. Each fix goes upstream as an issue or a pull request.

      Get the code

      git clone https://github.com/mark1russell7/wirelab.git
